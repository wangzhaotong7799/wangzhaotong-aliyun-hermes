## 二、内容供应链方案

### 2.1 素材来源（建议优先级）

| 来源 | 难度 | 质量 | 版权风险 | 策略 |
|:---|:---:|:---:|:---:|:---|
| **小红书**灵异话题 | ⭐ | ⭐⭐⭐⭐⭐ | 低 | 用户投稿型，标注来源 + 改写 |
| **豆瓣**灵异故事小组 | ⭐⭐ | ⭐⭐⭐⭐ | 低 | 授权合作或改写 |
| **知乎**灵异经历 | ⭐⭐ | ⭐⭐⭐⭐ | 低 | 改写 + 二次创作 |
| **Reddit** r/nosleep | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 低 | 翻译 + 本土化改编 |
| **用户投稿** | ⭐ | ⭐⭐⭐ | 无 | 粉丝互动 + 增加粘性 |
| **AI生成** | ⭐ | ⭐⭐⭐ | 无 | 用AI写初稿，人工润色 |

**核心原则**: 所有素材**必须二次创作**（改写+配音+配乐），不做纯搬运。

### 2.2 批量生产流程

```
每天早8点
  ↓
Step 1: 采集素材 (小红书/豆瓣/Reddit 抓取前日热帖)
  ↓
Step 2: AI清洗筛选 (去重、质量评分、长度控制)
  ↓
Step 3: 改写脚本 (AI润色 + 人工抽检)
  ↓
Step 4: 批量生成 (配音+BGM+背景→视频)  ← 已有脚本
  ↓
Step 5: 排期发布
```

### 2.3 建议产量

| 阶段 | 日产量 | 周产量 | 月产量 |
|:---|:---:|:---:|:---:|
| 试跑期 (第1-2周) | 1-2条 | 10条 | 40条 |
| 稳定期 (第3-4周) | 3-5条 | 25条 | 100条 |
| 规模期 (第2个月) | 5-10条 | 50条 | 200条 |

## 三、平台矩阵策略

### 3.1 首发平台选择

| 平台 | 推荐等级 | 理由 |
|:---|:---:|:---|
| **YouTube Shorts** | ⭐⭐⭐⭐⭐ | 长尾流量巨大，中文恐怖故事供给少，竞争低 |
| **抖音** | ⭐⭐⭐⭐⭐ | 国内最大池子，恐怖类是常青赛道 |
| **小红书** | ⭐⭐⭐⭐ | 女性用户为主，夜间接恐怖故事流量高 |
| **TikTok** | ⭐⭐⭐ | 需要英文内容，市场更广但竞争也大 |

### 3.2 发布节奏

```
周一至周五：每天1-2条
周六/周日：每天1条（周末流量高但竞争也高）

推荐时间段：
  抖音：     中午12点 或 晚上9-11点
  YouTube：  早上8-10点 (EST时间)
  小红书：   晚上10-12点 (恐怖故事黄金时段)
```

### 3.3 内容系列化

建议用 **固定的IP/栏目名**，打造品牌辨识度：

```
🎬 栏目名称建议：
  "夜半低语"     — 深夜恐怖故事
  "十三号房间"   — 悬疑案件合集
  "镜中人"       — 心理恐怖系列
  "你身后有人"   — 日常恐怖经历

频道视觉：
  - 固定片头 (3秒暗黑动画 + 栏目名)
  - 统一色调 (黑红风格)
  - 统一结束语 ("晚安，如果还睡不着...")

视频格式标准化：
  - 竖版 9:16 (1080×1920)
  - 时长 25-60秒 (Shorts标准)
  - 片头片尾固定3秒
```

## 五、商业化路径（纯副业模式）

### 路径A：YouTube Shorts 广告分成（核心）
```
YouTube Shorts 基金 / 广告分成
  → 1000订阅起付
  → 中文恐怖故事Shorts赛道竞争低，起量快
  → 预计：1万播放 ≈ $10-30 (Shorts基金时期)
  → 当前靠广告分成，Shorts流量大但单次收入不高
  
关键：多账号矩阵放大
  1个号月入$100 → 10个号月入$1000
```

### 路径B：多平台分发 + 抖音中视频计划
```
一条视频 → 多端分发（零边际成本）
  YouTube Shorts → 美金收益
  抖音          → 中视频计划/创作者激励
  小红书        → 品牌合作机会
  TikTok        → 海外变现
  
一套内容吃多份钱
```

### 路径C：账号矩阵复制（放大）
```
恐怖故事号 (已验证)
  ↓ 同一套自动化流水线
悬疑解说号 (同受众)
  ↓
冷知识科普号 (新赛道)
  ↓
搞笑段子号 (再复制)
  
核心优势：流水线搭好之后，换个脚本就是一个新号
```

### 路径D：卖铲子（进阶）
```
如果这个自动化流程跑通了
  → 把工作流做成产品/教程/SAAS
  → 卖给想做短视频但不会做的人
  → 从"搬砖"变成"卖工具"
```
