# 🎬 可灵（Kling）换产品翻拍工作流 v1.0

> 适用场景：找到爆款视频 → 用可灵翻拍 → 只换产品，其他几乎不变

---

## 一、整体流程

```
爆款视频下载
    ↓
影墨小队拆解（帧捕手+画师+执笔）
    ↓ 产出：逐镜分析报告 + 产品替换适配说明
    ↓
写成 Kling prompt → 图生视频 / 文生视频
    ↓
每镜5-10秒，逐段生成
    ↓
多段拼接 → 成品视频
```

---

## 二、Kling 提示词规则（简述）

| 项目 | 说明 |
|------|------|
| 语言 | **中文**最佳，自然语言 |
| 长度 | 每段 100-300 字 |
| 格式 | 每段一个独立场景，分段写 |
| 运镜 | 简单为主（推拉摇移跟升降），Kling对复杂运镜理解一般 |
| 光线 | 自然描述即可，不需要过于专业的电影术语 |
| 负面词 | 在 prompt 中自然融入（"画面稳定无闪烁"） |
| 图生视频 | 用产品实拍图作为首帧，效果最好 |
| 声音 | Kling 支持带声音的输出 |

## 三、翻拍专用 Prompt 模板

### 🅰 图生视频模式（推荐）— 用产品图 + Prompt

```
[场景名]

[画面描述]
一只手/场景从X角度入画，手中握着我们的{产品名}。
{产品名}的颜色是{颜色}，材质是{材质}。
光线从{方向}照射，在产品表面形成{效果描述}。
镜头{运镜描述}，背景是{环境描述}。

画面稳定，产品细节清晰，无闪烁无变形。
```

**示例**（五合一婴儿水杯套装翻拍）：
```
开箱展示

一双手从画面右侧入画，拿起我们的五合一婴儿水杯套装。
水杯主体是柔和的莫兰迪蓝色，硅胶吸管是半透明的。
暖白色侧光从左上方打来，在磨砂杯体表面形成柔和的漫反射。
镜头缓慢推进，从全景过渡到水杯细节特写。
背景是干净的木纹桌面，画面柔和高清。
画面稳定不闪烁，产品细节清晰。
```

### 🅱 纯文生视频模式 — 无参考图时

```
[场景名] ~{X}s

{画面构图}，{主体描述，含产品特征}.
{动作描述}，{环境氛围}.
机位{景别}，镜头{运镜方式}，光线{方向+效果}。
整体风格{风格标签}，色调{色温描述}。
```

**示例**：
```
婴儿场景展示 ~8s

前景是可爱的婴儿小手，正在抓握五合一水杯的防滑手柄。
水杯是莫兰迪蓝色磨砂质感，吸管盖自动弹开。
自然光从窗户洒入，在杯体表面形成柔和高光。
机位平视中景，镜头缓慢环绕。光线明亮柔和，奶白色调。
整体风格温馨自然，色调偏暖。
画面稳定不闪烁，产品细节清晰。
```

## 四、产品替换对照表（翻拍必看）

翻拍爆款视频时，分析原视频后按此表替换：

| 原视频元素 | 替换为 | 是否改Prompt |
|-----------|--------|:----------:|
| 原产品外观 | 我们的产品（颜色/材质/形状） | ✅ 必改 |
| 产品大小/比例 | 根据实际产品调整描述 | ✅ 必改 |
| 原产品Logo | 我们的Logo（如有） | ✅ 必改 |
| 场景/背景 | 保持原样 | ❌ 不改 |
| 光线方向/效果 | 保持原样 | ❌ 不改 |
| 运镜方式 | 保持原样 | ❌ 不改 |
| 情绪/氛围 | 保持原样 | ❌ 不改 |
| 颜色调性 | 保持原样（如果产品颜色不同，调prompt补偿） | ⚠️ 微调 |
| 视频节奏 | 保持原样 | ❌ 不改 |

**核心原则**：只改「产品本身」和「与产品直接互动」的部分，运镜/光线/构图/节奏全部保持。

## 五、爆款视频 → Kling 翻拍 全流程示例

### 假设：找到一个婴儿水杯爆款视频

**Step 1** — 帧捕手分析原视频：
```
时长: 25s | 6个场景
场景1(0-4s): 开箱手部特写
场景2(4-9s): 产品摆拍旋转展示
场景3(9-14s): 手柄特写+防漏演示
场景4(14-19s): 吸管打开动作
场景5(19-23s): 宝宝喝水场景
场景6(23-25s): 产品+Logo组合
```

**Step 2** — 替换产品描述为我们的五合一水杯

**Step 3** — 写成6段Kling可用的翻拍prompt：
```
1. 开箱手部 (0-4s)
一双手打开包装盒，从盒中取出五合一婴儿水杯套装。
水杯是莫兰迪蓝色磨砂质感，暖白侧光。
镜头缓慢上移，跟随手部动作。
画面稳定，产品细节清晰。

2. 产品展示 (4-9s)
五合一水杯在旋转台上匀速旋转，灯光从左上方照亮杯体。
磨砂表面呈现柔和的漫反射质感，防滑手柄清晰可见。
镜头缓慢环绕产品一周。

3. 细节特写 (9-14s)
手指按压水杯手柄，展示防滑纹理。
镜头推进到手柄特写，产品材质细节丰富。
侧逆光打亮手柄轮廓。

4. 功能演示 (14-19s)
手指按下按钮，吸管盖自动弹开。
镜头跟随吸管弹开的动作。背景干净白色。

5. 宝宝场景 (19-23s)
宝宝小手握住水杯手柄，吸管送到嘴边。
自然光从侧面打来，画面温馨暖色调。
镜头平视中景。

6. 收尾 (23-25s)
产品置于木桌中央，Logo置于右下角。
柔光从顶部打亮，画面干净整洁。
镜头从产品拉远到全景。
```

**Step 4** — 每段用 Kling 图生视频（以产品实拍图为首帧）或文生视频生成

**Step 5** — 6段拼接为 25 秒完整视频
