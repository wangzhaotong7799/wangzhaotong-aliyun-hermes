## 第一章 选片标准

### 1.1 什么样的爆款视频值得翻拍

不是所有爆款都值得翻拍。用以下评分矩阵筛选：

| 维度 | 权重 | 评分标准（1-5分） | 如何判断 |
|------|:----:|:----------------:|---------|
| 产品匹配度 | 30% | 5=同品类同价位 / 3=同品类不同价位 / 1=不同品类 | 是否与我们产品形态相似 |
| 可翻拍性 | 25% | 5=纯产品展示无人物 / 3=有人物但易替换 / 1=人脸出境难处理 | 产品占画面比例越高越好 |
| 画面复杂度 | 20% | 5=单场景/简单背景 / 3=2-3场景 / 1=多场景/复杂特效 | Kling擅长简单场景 |
| 数据验证 | 15% | 5=万赞+完播率高 / 3=千赞 / 1=百赞 | 点赞/评论/转发数据 |
| 光线可控性 | 10% | 5=棚拍/自然光 / 3=混合光 / 1=特效光/动感光 | 光线越稳定翻拍越准 |

**翻拍决策**：
- **总分 ≥ 4.0**：值得翻拍
- **3.0-3.9**：需降低期望，重点调整
- **< 3.0**：换一条视频

### 1.2 母婴喂养产品的优先赛道

按过往数据排序：

```
① 开箱/产品展示 → 翻拍最容易，效果最稳定
② 功能演示（防漏/易握/一键开盖） → 转化率最高
③ 宝宝使用场景 → 需注意宝宝形象，限制多
④ 多产品组合 → 难度高但客单价高
⑤ 场景化叙事（外出/家庭） → 转化路径长
```

**建议首发赛道**：先翻拍「产品展示+功能演示」类，跑通流程后再挑战场景化视频。

## 第三章 翻拍Prompt生成（核心）

### 3.1 核心原则

| # | 原则 | 说明 |
|:-:|------|------|
| 1 | **只换产品，不换片** | 原视频的运镜/光线/构图/节奏全部保持 |
| 2 | **光材交互必须写** | 光在产品表面的相互作用是翻拍质量的命门 |
| 3 | **原片气氛不丢** | 写prompt时先从原帧的气氛描述开始，再替换产品 |
| 4 | **Kling偏好中文自然语言** | 不用太多专业电影术语，自然中文描述最好 |
| 5 | **每一个镜头独立写** | 不同镜头独立写prompt，不要混在一个prompt里 |

### 3.2 产品替换描述规则

#### 通用替换公式

```
原片产品特征描述 → 替换为 我们的产品特征描述
```

**需替换的维度**：

| 维度 | 原视频（举例） | 我们的产品 | 替换方法 |
|------|-------------|-----------|---------|
| 产品名 | "硅胶奶瓶" | "五合一婴儿水杯套装" | 直接替换 |
| 颜色 | "透明瓶身" | "莫兰迪蓝色磨砂杯体" | 颜色+材质 + 工艺 |
| 材质 | "硅胶" | "Tritan材质磨砂表面" | 材质名 + 表面处理 |
| 尺寸 | "小巧单手可握" | "适合宝宝小手握持" | 尺寸描述改为符合实际 |
| 特征 | "宽口径" | "防漏吸管+防滑手柄" | 逐个特征替换 |
| 灯光效果 | "透明瓶身透光" | "磨砂表面柔和漫反射" | 材质→光效映射 |

#### 光材交互描述库（直接复制使用）

**适用于不同材质的光线描述：

| 材质 | 光线描述模板 |
|------|-----------|
| 磨砂塑料 | "柔和漫反射，光线在磨砂表面均匀散开，无锐利高光" |
| 亮面塑料 | "表面反射出清晰的高光点，光线沿着曲面形成渐变高光带" |
| 硅胶 | "半透明质感，侧逆光下边缘微微透光，触感柔软的视觉效果" |
| 不锈钢 | "镜面反射，光线在高光面形成锐利的反射像" |
| 玻璃 | "透明质感，边缘折射出彩虹光，光线穿透后在桌面投下柔光阴影" |
| 磨砂玻璃 | "半透明，背光时呈现柔和的发光效果" |
| 布艺/纺织 | "表面纹理清晰可见，光线在织物表面形成细腻的明暗过渡" |

**光材交互的高阶写法（专业级）**：

```markdown
✅ 专业级：
"暖白侧光从左上45°打在莫兰迪蓝色磨砂杯体上，光线在磨砂表面形成均匀的
 漫反射，杯体边缘出现一道柔和的轮廓光。杯体上的防滑硅胶纹理在侧光下
 呈现细腻的明暗起伏，每一个凸点都捕捉了微小的光斑。"

❌ 粗糙级：
"光线照亮产品"
```

### 3.3 Kling专用Prompt模板（6种场景）

```

【关键】手部动作的质感 + 产品第一眼的光效

一双手从画面{方向}入画，{手部动作}。
```

```
画面稳定，产品细节清晰。

✨ 替换要点：只改产品名+颜色+材质+光效描述，运镜和背景保持原片
```

```markdown
✅ 正确写法：
"画面稳定不闪烁，产品细节清晰，无变形"
"光线均匀，颜色真实自然，没有过度曝光"
"人物/手部动作流畅自然，无卡顿或跳帧"

❌ 错误写法：
"不要闪烁，不要变形"
"no flickering, no morphing"  (Kling英文输入效果差)
```

### 3.5 逐段生成时的逻辑衔接

多段视频翻拍时，每段prompt的结尾要写清楚**时间接续关系**：

```markdown
✅ 正确段间衔接：
段1结尾："镜头停留在产品正面全景"
段2开头："接上一段，镜头从产品正面全景开始推进到特写"

✅ 另一种写法：
段1结尾：在开箱展示结束位置，产品置于桌面
段2开头：接上段，产品已在桌面，镜头从全景推进
```

## 第四章 Kling生成操作指南

### 4.1 图生视频 vs 文生视频

| 模式 | 适用场景 | 翻拍效果 | 推荐度 |
|:----:|---------|:--------:|:-----:|
| **图生视频** | 有产品实拍图 | 构图画质最可控 | ⭐⭐⭐⭐⭐ |
| 文生视频 | 无产品图 | 构图容易偏 | ⭐⭐⭐ |

**翻拍时强烈建议用图生视频**：
- 先拍一张与爆款视频**构图一致**的产品照片
- 用这张照片作为 first_frame
- prompt只描述动作/光线变化

### 4.2 Kling平台设置建议

| 参数 | 推荐值 | 说明 |
|:----:|:------:|------|
| 模式 | 图生视频 | 首帧用产品图，效果最稳定 |
| 时长 | 5-10秒 | 每段独立生成，不要超过10秒 |
| 分辨率 | 1080p | Kling支持，比通义万相720p好 |
| 风格 | 自然/写实 | 翻拍不选特效风格 |
| 画面比例 | 9:16（竖屏）/ 16:9（横屏） | 跟原视频一致 |
| 创意度 | 低（0-3） | 翻拍要贴近原片，创意度越低越好 |

### 4.3 逐段生成策略

```
原片 25s
    ↓ 切为6段
段① 4s → Kling生成5s（留1s重叠便于拼接）
段② 5s → Kling生成6s（留1s重叠）
段③ 5s → Kling生成6s
段④ 6s → Kling生成7s
段⑤ 5s → Kling生成6s
段⑥ 2s → Kling生成3s
    ↓
拼接 → 成品 ~27s（含重叠部分）
```

**重叠拼接策略**：每段生成时长比原片对应段长1-2秒，方便后期剪辑时做转场过渡。

### 4.4 产品图的拍照规范

为了保证图生视频的效果，产品首帧图的拍摄要**尽量接近原视频构图**：

| 原视频镜头 | 拍照要求 |
|-----------|---------|
| 开箱手部 | 手拿产品的角度/光线/背景尽量一致 |
| 产品展示 | 产品摆放角度、桌面材质、灯光方向一致 |
| 细节特写 | 特写部位、对焦位置一致 |
| 功能演示 | 操作手势、产品姿态一致 |

**拍摄清单**：
```
□ 正面全景 — 与段②/段⑥的首帧对应
□ 45°角产品图 — 与段①/段③对应
□ 手柄特写 — 与段③对应
□ 吸管打开状态 — 与段④对应
□ 手部握持 — 与段⑤对应
```

## 第五章 质量检查清单

### 5.1 每段生成后的逐项检查

生成后对照原视频逐项检查，**任何一项不通过就重跑**：

| # | 检查项 | 标准 | 通过 | 不通过怎么办 |
|:-:|-------|------|:---:|------------|
| 1 | **产品外观** | 产品颜色/形状/大小是否与实物一致 | ☐ | 更新prompt中的产品描述，重跑 |
| 2 | **光线匹配** | 光线方向/色温/软硬是否与原片一致 | ☐ | 调整prompt中的光线描述 |
| 3 | **运镜匹配** | 镜头运动方式/速度是否与原片一致 | ☐ | 简化运镜描述或改为固定机位 |
| 4 | **背景匹配** | 背景/环境/桌面是否与原片一致 | ☐ | 补充背景描述细节 |
| 5 | **产品细节** | 产品材质/工艺/特征是否清晰 | ☐ | 图生视频提供更清晰的参考图 |
| 6 | **稳定性** | 画面是否稳定，无闪烁变形跳帧 | ☐ | 加入负面词"画面稳定不闪烁" |
| 7 | **情绪氛围** | 整体感觉是否与原片一致 | ☐ | 整体检查后调整prompt基调 |
| 8 | **长宽比** | 画面比例是否与原视频一致 | ☐ | 在Kling平台设置中选择 |

### 5.2 全片合成后的整体检查

| # | 检查项 | 标准 | 通过 |
|:-:|-------|------|:---:|
| 1 | **颜色一致性** | 各段之间产品颜色一致 | ☐ |
| 2 | **亮度一致性** | 各段之间亮度无明显跳跃 | ☐ |
| 3 | **节奏感** | 整体节奏与原片一致 | ☐ |
| 4 | **拼接平滑** | 段间过渡自然，无跳帧 | ☐ |
| 5 | **声音** | Kling自带声音是否与原片风格匹配 | ☐ |
| 6 | **产品识别度** | 看到视频的人能第一眼认出是什么产品 | ☐ |
| 7 | **购买冲动** | 看完后有"想买"的感觉 | ☐ |

## 第六章 迭代优化

### 6.1 常见失败模式及修复

| 失败现象 | 可能原因 | 修复方案 |
|---------|---------|---------|
| 产品颜色不对 | 色温描述不准确 | 检查HEX色值，补充「暖/冷色调」关键词 |
| 产品形状变形 | 产品描述与首帧图不一致 | 图文要一致，先拍好参考图 |
| 光线与原片不像 | 光线描述太笼统 | 按画师分析结果精准描述：光源方向+类型+色温+硬度 |
| 运镜与原片不像 | Kling对复杂运镜理解有限 | 简化运镜描述，或改为固定机位，后期剪辑加运动 |
| 画面闪烁/跳帧 | 无负面词或Kling不稳定 | 加入「画面稳定不闪烁不跳帧」 |
| 产品与背景比例不对 | 首帧图角度问题 | 重拍首帧图，确保产品在画面中的位置/比例与对应段一致 |
| 材质质感不像 | 材质描述太粗糙 | 从光材交互描述库中选择正确的材质描述模板 |
| 人脸效果差（第5段） | Kling对宝宝人脸生成不稳定 | 改为手部出镜/取消人脸 |

### 6.2 迭代流程

```
第一轮生成
    ↓ 检查 → 有≥2项不通过？→ 调整prompt → 重跑
    ↓ ≤1项不通过
进入第二轮（微调）
    ↓ 小范围修改 → 重跑不通过段
    ↓ 全部通过
进入第三轮（拼接+整体校对）
    ↓ 整体检查通过？
    ↓ 是 → 发布
    ↓ 否 → 修正后再次整体检查
```

### 6.3 跑量建议

产品翻拍不是一锤子买卖。建议：

1. **先翻拍1条** — 跑通整个SOP，验证流程
2. **用不同爆款视频翻拍同款产品** — 同一个产品拍3-5条不同风格的视频
3. **测数据** — 各平台投流测试，看哪条翻拍视频跑得好
4. **成功模板复制** — 把效果最好的翻拍模板保存下来，后续产品直接套用
