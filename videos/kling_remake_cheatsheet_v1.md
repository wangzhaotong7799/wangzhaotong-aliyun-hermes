# 🎬 可灵翻拍 Prompt 速查卡 v1.0

> 实战时直接打开此文件复制模板，不用翻长文档。
> 完整 SOP 见 `kling_remake_workflow_v1.md`

---

## 📌 核心原则（每次写prompt前读一遍）

```
① 只换产品不换片 → 运镜/光线/构图/节奏全部保持原样
② 光材交互是命门 → 光在材质表面的相互作用必须写具体
③ 每段独立写prompt → 不要混在一起
④ Kling喜欢中文自然语言 → 不用太多电影术语
⑤ 图生视频 > 文生视频 → 先拍好产品图作首帧
```

## 📌 6种翻拍场景模板（直接复制改）

### 模板① 开箱/首现 ~3-5s

```
[开箱展示 ~{X}s]

一双手从画面{方向}入画，{手部动作}。
手中展示的是{产品名}，{颜色}，{材质}。
光线从{方向}打来，{光材效果}。
镜头{运镜}，背景{环境}。
气氛{氛围}，画面稳定，产品细节清晰。
```

**示例**（改产品名+颜色+材质+光效，其他保持）：
```
开箱展示 ~4s

一双手从画面右侧入画，轻轻打开包装盒。
从盒中取出五合一婴儿水杯套装，莫兰迪蓝色磨砂杯体在暖白侧光下呈现柔和的漫反射质感。
暖白侧光从左上45°打来，杯体边缘形成一道柔和的轮廓光，光线在磨砂表面均匀散开。
镜头缓慢推进，从双手全景过渡到水杯中景。
背景是干净的木纹桌面，气氛温馨自然。
画面稳定，产品细节清晰。
```

### 模板② 产品展示 ~5-8s

```
[产品展示 ~{X}s]

{产品名}置于{表面}上，{摆放姿态}。
{颜色}的{材质}表面，{光材效果}。
背景{环境}，色调{主色调}。
镜头{运镜}，{速度}环绕/移动。
气氛{氛围}。
画面稳定不闪烁，所有细节清晰可见。
```

**示例**：
```
产品展示 ~6s

五合一水杯置于浅色木桌中央，杯体微微偏左，吸管向右展示。
莫兰迪蓝色磨砂表面在柔光下呈现均匀的漫反射，杯体边缘有柔和的倒角高光。
背景是干净的浅灰色墙面，整体色调暖白柔和。
镜头从产品正面缓慢环绕到侧面，约15°/秒。
气氛干净专业，有品质感。
画面稳定不闪烁，磨砂质感、防滑手柄、吸管盖细节清晰可见。
```

## 📌 Kling平台设置速查

| 参数 | 推荐值 | 说明 |
|:----:|:------:|------|
| 模式 | 图生视频 | 首帧用产品实拍图，效果最稳 |
| 时长 | 5-10s | 每段独立生成 |
| 分辨率 | 1080p | |
| 风格 | 自然/写实 | 翻拍不选特效风格 |

```
✅ "画面稳定不闪烁，产品细节清晰"

```

## 📌 常见问题速修

| 问题 | 修复 |
|------|------|
| 产品颜色不对 | 检查HEX色值 + 补充「暖/冷色调」关键词 |
| 光线不像原片 | 精确描述：光源方向+类型+色温+软硬 |
| 运镜不像 | 简化运镜描述，固定机位 → 后期剪辑加运动 |
| 画面闪烁 | 加入「画面稳定不闪烁」 |
| 产品变形 | 图生视频 vs 文生视频构图对照不符，重拍首帧图 |
| 人脸效果差 | 改为手部出镜，不出现人脸 |
| 材质质感差 | 从「光材交互描述速查」中选正确的材质模板 |

```
□ 产品颜色/形状/材质对不对
□ 光线方向/色温像不像原片
□ 运镜速度/方式像不像原片
□ 背景/环境像不像原片
□ 画面稳不稳，有没有闪烁
□ 整体感觉跟原片一样不一样
□ 各段之间颜色/亮度是否一致
□ 看完想不想买
```
