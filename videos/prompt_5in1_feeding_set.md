## 三、2秒钩子设计

根据钩子选择矩阵，母婴产品推荐 **④揭盖开箱** + **⑧自组装** + **⑫凝视入镜**：

### 开场钩子方案：④揭盖开箱 + ⑧自组装融合版

```
双手打开白色礼盒式包装，盒盖掀开的瞬间，
天蓝色配件整齐展现在透明瓶身周围——6个盖子
像积木般排列。手指拿起奶嘴盖"咔嗒"旋上瓶口，
再换成吸管盖、鸭嘴盖……"一拧切换"的核心卖点
通过手部动作直接在开场传递给用户。
```

## 四、逐镜头拆解（共7镜，已校准）

### 【镜头1】开箱揭幕 — "一盒五用"
| 参数 | 描述 |
|:----|:------|
| **时间** | 0-5s |
| **钩子** | ④揭盖开箱+⑧自组装 — 开盒后手指速拧3种盖子演示模块化 |
| **构图** | 俯拍45°，双手+礼盒居中，白色背景 |
| **景别** | 中近景（Medium Close-Up） |
| **运镜** | 固定机位带呼吸感，盒盖开的瞬间有微妙减速 |
| **光线** | 右侧自然侧光+顶柔光，暖调5000K `soft window light + gentle top fill` |
| **色调** | 天蓝(#5DADE2)配件 + 透明瓶身 + 白色(#FFFFFF)礼盒 |
| **情绪** | 好奇·惊喜·"这么多配件！" |

**视觉描写**：
```
俯拍45°，白色礼盒居中放在暖木纹桌面上。
双手从两侧入镜打开盒盖——天蓝色的奶嘴盖、
螺牙环、鸭嘴盖、吸管盖、密封盖、透明瓶身
整齐排列在内衬凹槽中。手指拿起奶嘴盖，
"咔嗒"一声旋到瓶口，再旋下，换上吸管盖。
这段速拧展示0-5秒内完成，直接传递"一拧切换"
的核心卖点。浅景深让背景家居柔化为光斑。
```

### 【镜头2】水杯模式展示 — 透明瓶身+刻度
| 参数 | 描述 |
|:----|:------|
| **时间** | 5-10s |
| **构图** | 手持45°展示，中心构图 |
| **景别** | 近景（Close-Up） |
| **运镜** | 微距推进→缓慢旋转360° |
| **焦点** | 浅景深，焦平面在瓶身刻度+卡通图案 |
| **光线** | 右侧自然侧光，暖调 `side window light` |
| **色调** | 透明瓶身 + 天蓝(#5DADE2)盖子 + 彩色卡通图案 |
| **情绪** | 精致·可爱·高品质 |

**产品细节描写**：
```
手从盒中取出透明瓶身，45°展示。瓶身透亮，
侧面的双单位刻度（ml+oz）清晰可见。
手指轻转瓶身，露出卡通小老鼠坐火车的图案——
粉色、紫色车厢，金色心形点缀。天蓝色手柄
与瓶身一体成型，无接缝。光线穿过透明瓶壁，
在桌面上投下柔和的光影。
```

### 【镜头3】多品速览 — 5种模式卡点
| 参数 | 描述 |
|:----|:------|
| **时间** | 10-14s |
| **运镜** | 硬切卡点+手部速拧转场 |

| **卡点序列** | ①奶瓶模式→②吸管杯模式→③鸭嘴杯模式→④敞口杯模式→⑤储物瓶模式 |

```
② 吸管杯：吸管盖+硅胶吸管

④ 敞口杯：密封盖带提手
⑤ 储物瓶：密封盖，展示内装奶粉的场景
每种切换用"咔嗒"音效配合卡点BGM。
```
