# 影墨小队 (Video Inverse Team) — 2026-05-12

## 🎯 核心创意 (Core Concept)

**视频类型**: 母婴用品开箱测评 / 好物分享
**叙事主线**: 从拆箱到展示到真实使用场景的完整产品体验流程
**目标受众**: 新手父母 / 母婴用品购买决策者
**核心信息**: "布比熊 Bubble Bear 儿童水杯——设计贴心、宝宝爱用、妈妈放心"
**整体节奏**: 先快后慢——开场快速开箱制造期待，中段逐个产品详细展示和操作演示，收尾回归温馨使用场景

## 🎨 视觉风格定义 (Visual Style)

### 色调板 (Color Palette)
| 色系 | 色值 | 占比 | 用途 |
|------|------|:----:|------|
| 暖橙 | `#FF8C42` | 35% | 产品主色、视觉焦点 |
| 浅蓝 | `#87CEEB` | 20% | 产品辅色、儿童感 |
| 白色 | `#FFFFFF` | 25% | 背景、包装、产品基色 |
| 米白 | `#F5F5DC` | 10% | 环境底色、台面 |
| 肤色 | `#FDDCB5` | 10% | 手部、婴儿面部 |

- **色温**: 全片暖调为主（18/18帧均为暖色或中性偏暖）
- **饱和度**: 中低到中高（商业展示段高饱和，生活段低饱和）
- **对比度**: 中等，画面柔和不刺眼

### 构图模式 (Composition Pattern)
| 类型 | 占比 | 说明 |
|------|:----:|------|
| **前景后景** | 61% | 手+产品置于前景，背景家居环境虚化 |
| **中心构图** | 28% | 产品居中正面展示，双手从两侧形成框架 |
| **其他** | 11% | 特写/大景别合集 |

- **景深**: 浅景深占95%，背景高度虚化，产品/手部清晰锐利
- **视角**: 多为俯拍(45°)和正面水平视角交替
- **产品位置**: 画面中央偏下 1/3 处，手从两侧或下方握持

### 光效方案 (Lighting)
| 光源 | 占比 | 说明 |
|------|:----:|------|
| 人造光（柔和顶光/侧光） | 55% | 均匀照明，轻微柔和阴影 |
| 自然光（窗边侧光） | 45% | 温暖自然，轮廓清晰 |

- **整体**: 柔和均匀照明，无强烈明暗反差，无硬阴影
- **风格**: 类似窗边日光的家居感，营造亲切温馨氛围

### 运动特征 (Motion Profile)
- **镜头运动**: 绝大部分固定机位拍摄，无明显推拉摇移
- **主体运动**: 手部操作（开箱→展示→按压→摇晃），婴儿吸吮饮水
- **速度感**: 动作缓慢清晰，无明显运动模糊（仅1帧有轻微晃动模糊）
- **转场**: 硬切为主，无特效转场

## 📋 镜头序列 (Shot Sequence)

### 镜头1：开箱引入 (0s - ~6s)
| 参数 | 描述 |
|------|------|
| **时长** | 约6秒 |
| **构图** | 前倾俯拍，手从两侧伸入画面打开包装盒 |
| **主体** | "布比熊"包装盒，双手撕开封条 |
| **动作** | 缓慢打开盒子，展示包装外观 |
| **色彩** | 白色包装+橙色品牌标识，暖调 |
| **镜头语言** | 建立场景，制造开箱期待感 |

### 镜头2-3：产品逐样展示 (~6s - ~24s)
| 参数 | 描述 |
|------|------|
| **时长** | 约18秒（含多个快速切换） |
| **构图** | 手持45°展示，中心构图为主 |
| **主体** | 卡通造型水杯、奶瓶、学饮杯等产品逐个呈现 |
| **动作** | 手持摇晃、展示细节、按压测试吸嘴 |
| **色彩** | 橙色+浅蓝产品在白色/米色背景前突出 |
| **镜头语言** | 每个产品2-4秒，展示功能卖点 |

### 镜头4-5：操作演示 (~24s - ~36s)
| 参数 | 描述 |
|------|------|
| **时长** | 约12秒 |
| **构图** | 手部特写，前景后景 |
| **主体** | 泡奶机、杯盖拆装、吸嘴按压等 |
| **动作** | 手指按压、旋转、拆卸配件 |
| **色彩** | 暖调，产品颜色作为视觉焦点 |
| **镜头语言** | 展示产品功能细节，解决用户痛点的"方便易用" |

### 镜头6：实景使用 (~36s - ~48s)
| 参数 | 描述 |
|------|------|
| **时长** | 约12秒 |
| **构图** | 中心构图，婴儿面部+产品 |
| **主体** | 宝宝使用学饮杯/奶瓶喝水 |
| **动作** | 吸吮、小手握持杯柄 |
| **色彩** | 暖调，画面更柔和 |
| **镜头语言** | 真实使用场景建立情感连接，证明"宝宝爱用" |

### 镜头7：收尾 (~48s - 52s)
| 参数 | 描述 |
|------|------|
| **时长** | 约4秒 |
| **构图** | 合集展示（大景深）或包装与实物对比 |
| **主体** | 多个产品堆叠展示，或包装+实物并排 |
| **色彩** | 暖调，产品集中展示形成视觉丰富度 |
| **镜头语言** | 强化品牌印象，形成购买冲动 |

## 🔄 产品替换适配说明 (Product Adaptation)

### ✅ 可替换部分（换同品类产品时改这些）
- 产品名称：从"布比熊水杯"改为你的产品名
- 产品主色调：如果新产品的配色不同，调整提示词中的颜色描述
- 包装盒设计：调整为新产品包装描述
- 品牌标识描述

### 🔒 保持不变部分（核心视觉结构）
- **温度氛围**: 全片暖调/暖白色温，家庭温馨感
- **构图方式**: 浅景深+前景后景，手部持握展示
- **节奏**: 开箱→逐个展示→功能演示→实景使用→合集收尾
- **光线方案**: 柔和侧光/顶光，无硬阴影
- **机位**: 基本固定机位，手持45°展示为主
- **风格**: 纪实感+商业感融合的母婴好物分享

### 💡 适配建议
- **替换同品类（儿童水杯/奶瓶）**：直接替换产品描述，风格几乎不需调整
- **替换为其他母婴产品（玩具/衣物）**：保持节奏和拍摄方式，调整产品展示角度
- **替换为非母婴产品**：去掉"婴儿实景使用"镜头，改为更通用的"产品使用演示"

## ⚠️ 生成注意事项
- **Negative Prompt**: 强烈阴影、高对比度、冷色调、闪光灯效果、人物全身、专业影棚感（如需保持生**活感**）
- **一致性提升**: 建议使用同一参考图作为 style reference 进行图生视频
- **时长**: 输出的短视频建议15-20秒（平台限制），选择最关键的3-4个镜头作为生成内容
