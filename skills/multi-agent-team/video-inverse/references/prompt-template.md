# 视频提示词模板 — 参考

## ¥ 提示词构成要素

1. **核心创意** — 视频的中心思想（不可替换）
2. **视觉风格** — 色调、构图、光效的统一定义（建议保持一致）
3. **镜头序列** — 逐个镜头的细节描述（可微调）
4. **产品替换适配说明** — 换产品时改什么、不改什么

## ¥ 不同平台的提示词差异

| 平台 | 格式偏好 | 字数限制 | 特殊参数 |
|------|---------|---------|---------|
| Runway Gen-3 | 自然语言描述 | 无明确限制 | 支持 camera_shot 参数 |
| Kling | 中文自然语言 | 500字以内 | 支持 start/end frame |
| Seedance | 英文描述 | 200字左右 | 支持 style reference |

## ¥ 提示词质量检查清单

- [ ] 是否包含核心创意描述？
- [ ] 色调、构图、光效是否都有明确说明？
- [ ] 镜头序列是否有时长标注？
- [ ] 是否标注了可替换和不可替换部分？
- [ ] 是否附带了目标平台的提示词版本？
