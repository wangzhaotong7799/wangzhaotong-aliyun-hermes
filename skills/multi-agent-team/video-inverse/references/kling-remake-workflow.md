## SOP核心流程

```
选片（评分矩阵→≥4.0分）
  → 下载原视频
  → 帧捕手智能分析（场景检测+CV智能帧选择）
  → 画师逐帧分析（8维度/帧，Qwen-VL-Max）
  → 执笔按6模板写Kling prompt（只换产品描述）
  → 图生视频逐段生成
  → 8项每段质检 → 7项整体质检
  → 全部通过 → 发布
```

## 翻拍铁律

1. 只换产品不换片 — 运镜/光线/构图/节奏全部保持原样
2. 光材交互是命门 — 光在产品材质表面的相互作用决定翻拍成败
3. 每段独立写prompt — 不同镜头不要混在一起
4. Kling喜欢中文自然语言 — 不用太多电影术语
5. 图生视频 > 文生视频 — 先拍好产品图作首帧
