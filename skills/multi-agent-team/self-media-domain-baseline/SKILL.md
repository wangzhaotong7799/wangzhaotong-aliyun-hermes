# 自媒体域研究基准（Self-Media Domain Baseline）

> 用途：金脉小队（wealth-analyst）执行自媒体域周报时加载，获取最新评分排名、平台政策、失败案例和搜索词库。数据更新：2026-08-03。

## 一、域参数（与 wealth-analyst domain-adaptation.md 域案例一一致）

```
域：自媒体
赛道（8个）：短剧、本地生活、教育知识、美妆、美食、母婴、数码、健身
数据平台（6个）：抖音、小红书、B站、视频号、快手、TikTok
评分维度：变现效率(0.35) + 竞争强度(0.25,逆分) + 供给饱和度(0.25,逆分) + 生命周期(0.15)
```

**❗ 评分维度计分约定（2026-06-29 确认，2026-08-03 再验证）**
- **变现效率**：原始分（越高越好）。8/10 = 变现能力强
- **竞争强度**：**逆分**（越低越不利）。3/10 = 竞争极度激烈，7/10 = 竞争温和
- **供给饱和度**：**逆分**（越低越不利）。2/10 = 极度饱和，7/10 = 还有蓝海
- **生命周期**：原始分（越高越好）。8/10 = 高速成长期，5/10 = 成熟期
- **总分** = 变现×0.35 + 竞争×0.25 + 供给×0.25 + 生命×0.15
- 若四维度均用原始分，高变现×高竞争×高饱和赛道（如美妆）会被误推至第一，与实际"最红海"感知不符——**逆分处理是正确做法**。

### 2026-08-03 关键发现（评分依据）

1. **本地生活登顶**：抖音本地生活2025交易额破万亿 + 36氪《2026全国连锁商家抖音经营报告》+ 真实案例"45天净赚30万"（36氪 2026-07-27）；但8成探店达人难过万（36氪 2026-06-12）、本地推算法改"长效赛马"（考核周期24h→7天，收藏率权重升第一梯队，硬广打法失效）。
2. **健身跃居第二**（+0.53 涨幅第一）：小众运动（HYROX/徒步/骑行）成年轻人"精神自救"新风口（新浪 2026-06-22）+ 体育明星批量走进直播间带货（36氪 2026-07-19）；垂类深度内容（中老年/康复/产后）仍稀缺。
3. **短剧从第一回落**（-0.72）：红果取消真人保底 + AI短剧泡沫破裂（2100家企业注册/创业者3个月亏20万/头部单季亏7亿，21经济网 2026-06-08）；但 QuestMobile 用户7.18亿、营销报告称8亿用户奠定价值，进入精品化洗牌期。
4. **教育知识重大政策**：三大平台（抖音/小红书/快手）教育类目**定向邀约制**落地——个人账号失去自有课程上架权限，仅可官方课程分销（CSDN 2026-07-29）。个人入局门槛骤升。
5. **美妆仍垫底但微升**：微型KOL全面超越头部（1-10万粉互动率4.2% vs 百万粉1.1%，marketingtochina 2026-06-18）+ 原生淡妆/精简护肤新叙事（千瓜2026上半年报告）。
