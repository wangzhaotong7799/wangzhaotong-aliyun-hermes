## 二、经验记录

### 翻拍Prompt结构
- 标准格式: 2秒钩子框架 + 场景分解6步法 + 负面词
- 时间精度: 3秒级，模糊描述一律不用

### 风格模板
- 6种翻拍场景模板：开箱/展示/特写/功能/场景/收尾
- 每个模板含：Camera Movement + Lighting + Background + Props + Action

### 输出格式
- Word文档交付，标题：「翻拍提示词_<产品名>.docx」
- 内附时间线对照表
