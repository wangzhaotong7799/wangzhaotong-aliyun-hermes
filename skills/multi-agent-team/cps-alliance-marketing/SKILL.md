## 二、评分维度定义（CPS域专用）

| 维度 | 权重 | 解释 |
|:----|:---:|:-----|
| 市场规模 | 15% | 赛道GMV/返利市场总量 |
| 增长潜力 | 20% | 同比增速、渗透率空间、平台投入力度 |
| 竞争格局 | 15% | 推广者数量、内卷程度、平台垄断性 |
| 利润率 | 20% | 佣金率、客单价、复购对LTV的影响 |
| 门槛难度 | 15% | 入门所需技能/资源/工具成熟度 |
| 风险控制 | 15% | 平台政策稳定性、单一平台依赖风险 |

## 四、已验证搜索词模式

对每个赛道，使用以下组合词确保召回率：
```
2026年 [赛道名] [平台1] [平台2] [维度1] [维度2]
```

详见 `references/cps-working-searches.md`（18条已验证搜索词）。

**通用模板参数**：
- 赛道名：外卖CPS / 电商CPS / 本地生活CPS / 社交裂变CPS / 短视频带货CPS / 跨境CPS
- 平台1/2：对应赛道主力平台（美团联盟/淘宝联盟/抖音/Shopee等）
- 维度1：佣金 / 政策 / 趋势 / 返利
- 维度2：规模 / 市场 / 推广 / 变现
