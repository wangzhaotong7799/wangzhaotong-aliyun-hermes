## 🔗 跨队调用：天网（素材采集）

编剧需要找新故事时，直接按以下格式呼叫天网：

```
📨 [天网请求]
   来自: 搬砖大队·编剧
   需求: 搜鬼故事素材
   输入: 关键词=["鬼故事 短篇 恐怖" "灵异事件 短篇" "民间恐怖传说"]
   数量: 5-10
   输出格式: 标题+全文链接+平台来源
   紧急: 低
```

天网收到后会回复：
```
📡 [天网回复]
   状态: ✅ 完成
   采集方法: baidu_direct + sogou_direct
   结果:
   | # | 标题 | 来源 | 链接 |
   |---|------|:----:|:----:|
   | 1 | ... | ... | ... |
   数据已保存: {路径}
```

编剧拿到链接后，用 `web_extract` 提取全文，进入清洗+标注流程。
