## 三、经验记录

- **光线描述是翻拍质量的命门** — 光源方向 + 色温 + 软硬 + 阴影特征，缺一不可
- **光材交互必须写** — 光在材质表面的相互作用：磨砂=漫反射、亮面=高光点、硅胶=半透光
- **如果画面太暗或过曝**，在分析中标注「质量受限」，让执笔写prompt时针对性补偿
- **关键帧（场景切换帧、产品帧）用 Max 分析**；普通过渡帧可以用 Plus 省钱
