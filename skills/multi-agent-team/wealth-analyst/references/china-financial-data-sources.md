# 中国金融市场数据源（当 web_search 不可用时的备选方案）

当 `web_search` / `web_extract` 工具因限额不可用时，可通过终端直接采集 A 股、H 股行情和基本面数据。以下为经过验证的免费 API 通道。

---

## 一、实时行情

### 腾讯财经 API（推荐，稳定）`

通用查询格式：

```bash
curl -s "http://qt.gtimg.cn/q=sh601398,sh601288,sh600036" | iconv -f gbk -t utf-8
```

返回 `~` 分隔的字段，关键位置：
| 字段位置 | 含义 | 示例 |
|---------|------|------|
| [3] | 最新价 | 7.23 |
| [4] | 昨收 | 7.31 |
| [5] | 今开 | 7.34 |
| [6] | 成交量(手) | 3635366 |
| [33] | 最高价 | 7.34 |
| [34] | 最低价 | 7.22 |
| [37] | 成交额(万元) | 263977 |
| [39] | 市盈率(PE) | 6.94 |
| [43] | 振幅% | 1.64 |
| [44] | 流通市值(亿) | 19492.96 |
| [45] | 总市值(亿) | 25768.17 |
| [46] | 市净率(PB) | 0.66 |

代码前缀规则：上海 `sh`，深圳 `sz`（如 `sz000001`）。

批量查询示例：

```python
import urllib.request
codes = ["sh601398","sh601939","sh601288","sh601988","sh600036"]
url = f"http://qt.gtimg.cn/q={','.join(codes)}"
req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
with urllib.request.urlopen(req, timeout=15) as resp:
    raw = resp.read().decode('gbk')
```

### 新浪财经 API

```bash
curl -s "https://hq.sinajs.cn/list=sh601398,sh601939" -H "Referer: https://finance.sina.com.cn"
```

注意需要设置 `Referer` 头，否则返回空。编码为 GBK。

## 二、基本面数据（PE/PB/市值）

腾讯 API（`qt.gtimg.cn`）已经包含了 PE、PB、总市值等关键字段，不需要额外查询。

---

## 三、分红数据

腾讯和新浪的行情接口**不包含**分红记录。分红数据需要从以下来源获取：

1. **2024年年报/2025年分红方案** — 通常已在财经新闻和公告中披露
2. **东方财富分红融资页** — `https://data.eastmoney.com/yjfp/{code}.html`
3. **同花顺分红页** — `https://basic.10jqka.com.cn/{code}/bonus.html`

> ⚠️ 东方财富与同花顺页面均为 JavaScript 客户端渲染，爬取难度高。分红数据建议：
> - 通过已知的官方公告获取（年度分红方案公告）
> - 或使用搜索引擎查找历史分红数据（当 `web_search` 可用时）
> - **不要编造或估算分红数据**，标注为"基于已知公告的参考值"

## 五、注意事项

1. **腾讯 API 的 GBK 编码** — `qt.gtimg.cn` 返回 GBK 编码。`urllib` 读取后需 `.decode('gbk')`。简体中文名可能出现乱码（如"XD工商银"显示为"XD锟斤拷锟斤拷"），不影响数值解析。
2. **新浪 API 的 Referer 要求** — 必须设置 `Referer: https://finance.sina.com.cn` 头，否则被拒绝。
3. **腾讯 API 字段稳定性** — Tencent 偶有字段位置调整，每次使用时先用 raw 输出检查前 50 个字段的对应关系。
4. **H 股（港股）用 `hk` 前缀** — 如 `hk01288`。
5. **分红数据精确度** — 各银行2024年度的正式分红方案（含中期+末期）应以股东大会通过的公告为准。使用估算值时必须标注"基于已公布的参考值"。

## 六、完整分析示例：银行股评分

当需要对多支股票进行综合评分时，推荐流程：

1. **采集股价+基本面** — 腾讯API批量查询所有目标股票
2. **获取分红方案** — 从已知的2024年年报公告中提取
3. **建立评分模型** — 按维度（股息率30% / 估值25% / 成长性20% / 安全边际25%）加权
4. **输出矩阵** — 含排名、各维度分、总分

> 该流程在 2026-05-13 的银行股分析中已验证有效（13 支 A 股银行，采集 + 评分 + 报告共 ~78 秒，3 次 API 调用）。
