## 域案例一：自媒体（已验证 ✅）

**首次运行验证通过**（2025年5月2日），产出 180 行/17.5KB 专业报告。

```
域：自媒体
赛道：美妆、数码、教育、母婴、短剧、本地生活、健身、美食
数据平台：抖音、小红书、B站、视频号、快手、TikTok
评分维度：变现效率(0.35) + 竞争强度(0.25) + 供给饱和度(0.25) + 生命周期(0.15)

**❗ 评分维度计分约定（2026-06-29 确认）**
- **变现效率**：原始分（越高越好）。8/10 = 变现能力强
- **竞争强度**：**逆分**（越低越有利竞争环境）。3/10 = 竞争极度激烈（不利），7/10 = 竞争相对温和（有利）
- **供给饱和度**：**逆分**（越低越有利供给环境）。2/10 = 极度饱和，7/10 = 还有蓝海空间
- **生命周期**：原始分（越高越好）。8/10 = 高速成长期，5/10 = 成熟期
- **总分公式** = 变现效率×0.35 + 竞争强度×0.25 + 供给饱和度×0.25 + 生命周期×0.15
- **历史验证**：2026-06-22 自媒体域报告中美妆赛道标注"竞争强度3/10+供给饱和度3/10"确认此约定。若四个维度均用原始分计算，美妆会因高变现×高竞争×高饱和被推至排名第一，与实际"最红海"的市场感知严重不符。逆分处理是正确做法。
报告章节：6章（摘要→排行→平台→案例→路线图→风险）
失败案例关键词："自媒体 亏了"、"MCN 倒闭"、"达人 翻车"、"平台 纠纷"
数据引擎：Firecrawl(深爬) + Exa(语义) + Tavily(实时)
```

**2026-06-22第五次验证**（CRON_MODE, 手动Exa搜索, 14次）：
- 98条→83条有效（84.7%通过率），8赛道均≥5条
- **评分排名**：短剧(7.00) > 本地生活(6.50) > 母婴(6.45) > 美食(6.40) > 教育知识(6.15) > 数码(6.10) > 健身(5.85) > 美妆(5.05)
- **关键发现1**：短剧跃居第一（QuestMobile 7.18亿用户+抖音15亿加码+AI/真人双轨增长），回调前期偏悲观预期
- **关键发现2**：美妆跌至最后（竞争强度3/10+供给饱和度3/10——"演员"泛滥揭示出极端同质化）
- **关键发现3**：教育知识从7.50回调至6.15——前期评分偏高，赛道天花板低于短剧和本地生活
- **关键发现4**：Exa `publishedDate` 字段持续可靠，本次大量条目自带发布日期，年份验证无需全依赖URL提取
- **新增平台政策**：抖音付费点播上线、达人服务费新规7月8日生效、抖音MCN放权规范化

## 重要注意事项

1. **无数据时不要编造** — 某个域没有足够公开数据时，标注"数据不足"并建议付费数据源
2. **按域调整预期** — 自媒体数据最丰富（6大平台×8赛道），电商次之，硬件选型数据分散需要多平台交叉验证
3. **三引擎切换** — Firecrawl 适合深爬已知页面，Exa 适合语义搜索行业报告，Tavily 适合实时热点
4. **多域联动** — 一个域内的赛道可能跨域（如"直播带货"横跨电商+自媒体），按主要域归类即可
5. **硬件域的特殊性** — 价格数据分散、实际成交价与指导价有差距、标称带机量和实测不同，多个来源交叉验证
6. **需求追加处理** — 硬件选型用户常会在初期报告后追加条件（如"要能管理AP"），需二次补采数据再更新报告
