## 一、Top 3 赛道策略

### 🥇 社交裂变CPS（7.35）— 核心战场：微信私域 + 有赞/微信小店体系

**策略定位**：第一优先级，主攻社群+私域分销，复用有赞客CPS/微信小店优选联盟基建。

1. **社群裂变打法**：以"省钱刚需"钩子建群（外卖券+电商券+本地券混合），用有赞分销系统设置多级分佣，老客带新客（有赞"老客带新裂变营销"产品线已验证成熟）。
2. **微信推客红利**：微信小店推客佣金计算时效规则明确（有赞帮助中心），推客3.0渠道值得卡位——分享渠道佣金结算规则已标准化。
3. **合规红线**：2026年微信已封杀朋友圈打卡类裂变（36氪），梦饷"兜宝好物高佣金发展下线"私域乱象被腾讯新闻曝光（2026-03/04）——**严禁涉传销式多级分销**，佣金层级控制在1-2级，产品为真实消费券而非"拉人头返利"。
4. **LTV预估**：社群用户 50-200元/月（省钱刚需粘性最高），头部社群可破500元/月。

**行动清单（30/60/90天）**：
- 30天：搭建有赞分销商城+微信小店优选联盟账号，建3个主题社群（外卖/电商/本地）
- 60天：上线老客带新裂变活动（合规版），跑通分佣结算链路
- 90天：复制社群模型至10个群，月GMV目标10-30万

### 🥈 本地生活CPS（6.70）— 核心战场：抖音团购CPS + 美团联盟到店

**策略定位**：第二优先级，本月最大跃升赛道。抖音加码团购调佣（"背刺美团"，36氪）+ 美团到店承压，CPS红利窗口打开。

1. **抖音本地CPS卡位**：抖音开放平台已提供生活服务CPS接入指南+短视频定向佣金计划+通用佣金计划（官方文档），服务商/代运营角色利润空间大。
2. **酒旅CPS差异化**：抖音猛攻酒旅（36氪）、京东酒旅"免佣神话"后真相浮出水面（36氪）——酒旅高客单高佣金，但需内容运营能力，适合有探店资源的团队。
3. **达人两极分化**：头部达人月入30万但8成难过万（36氪）——不要All in做达人，做"工具+供应链"型CPS服务商更稳。
4. **LTV预估**：单用户到店 50-200元/单，酒旅500-2000元/单；复购周期长但客单高。

**行动清单**：
- 30天：入驻抖音开放平台CPS（服务商模式），选定2-3个本地品类（餐饮/酒旅/丽人）
- 60天：绑定20-50家本地商户，上线短视频定向佣金计划
- 90天：跑通"内容种草→到店核销→佣金结算"闭环，月佣金收入目标1-5万

### 🥉 电商CPS（6.20）— 核心战场：京东联盟 + 返利工具

**策略定位**：第三优先级，存量稳健型赛道。京东Q3上调类目佣金（公告2026）+ 淘宝客佣金计算规范更新，佣金结构正在重塑。

1. **京东联盟Q3红利**：类目佣金比例调整公告已出，优先选佣金上调类目（高佣类目白名单）。
2. **返利工具合规化**：联盟API链接类请求合规改造通知（TaoKeShow 2026-06）——技术型淘客需升级API合规能力，这是新的准入壁垒，利好有技术团队者。
3. **返利App市场**：返利市场或达2200亿（网界2026-06），实测返利App混战（新浪2026-04/05），工具型玩家仍有空间但需差异化（比价+返利+优惠券聚合）。
4. **LTV预估**：返利用户 20-100元/月，工具型留存强于公众号型。

**行动清单**：
- 30天：注册京东联盟+淘宝联盟，梳理Q3高佣类目
- 60天：上线合规返利小程序/App（API合规改造后的链路），接入高佣类目
- 90天：私域导流沉淀，月订单目标3000+单

## 二、谨慎入局/观望赛道

### 短视频带货CPS（6.10）
- 抖音精选联盟佣金门槛1%→5%已生效（京报网2026-03），内容成本高企
- 但"告别坑位费、纯佣结算优先级提前"（运营派2026）是利好——纯佣玩家成本下降
- **建议**：有内容制作能力的团队可入，纯投放型玩家回避

### 外卖CPS（5.75）
- 外卖券公众号"从月入百万到账号被封"生死时速（36氪2026）——微信治理公众号返利号风险高
- 美团私域拉新佣金更新频繁（云瞻平台多条公告），政策波动大
- **建议**：个人练手可做，但不要依赖单一公众号渠道；矩阵化+私域沉淀

### 跨境CPS（5.20）
- 三重政策打击：亚马逊"Onsite Commission Scope"同类不再计佣（idcbuy 2026）、Shopee新加坡最低佣金率6%（出海网2026）、TikTok Shop联盟资格恢复14天+双端健康分准入（AMZ123/allymatic 2026-07）
- **建议**：暂缓重投入，跟踪TikTok Shop东南亚联盟新规落地情况，Shopee新加坡6%最低佣金机制下选品策略需重算

## 四、风险清单

1. **微信生态收紧**：私域裂变/多级分销合规红线（涉传风险），梦饷案例已敲警钟
2. **抖音调佣持续**：佣金门槛已1%→5%，外链20%服务费，内容成本高企
3. **跨境政策叠加**：亚马逊/Shopee/TikTok Shop三方同时调佣，政策稳定性3.5分垫底
4. **返利工具合规**：联盟API合规改造淘汰无技术能力的小淘客
5. **公众号返利号治理**：微信对外卖券/返利公众号封号力度加大
6. **反垄断监管**：平台间比价返利可能触及价格秩序红线（2026中国电商格局竞争焦点为价格秩序）
