## 四、典型案例

### 4.1 成功案例

| 案例 | 亮点 | 启示 |
|:---|:---|:---|
| 视频号AI主播 | 618增长6倍，银发代购+大健康场景 | 技术+银发红利，公私域联动是核心壁垒 |
| 微信小店品牌商家 | 品牌领跑大盘增速4.3倍，中高端商品GMV贡献过半 | 中高端定位在视频号更吃香 |
| 小红书千万商家 | 千万商家达去年5.4倍，单场千万买手3.6倍 | 店播+买手双轨，低粉素人可起量 |
| 淘宝闪购 | 订单份额42%（瑞银口径），阿里战略支柱 | 平台战略级投入=商家确定性红利 |

### 4.2 失败案例（必须引以为戒）

| 案例 | 教训 |
|:---|:---|
| 75亿自嗨锅破产 | 网红品牌流量起量但供应链/复购跟不上，流量退潮即崩盘 |
| 蓝月亮解散达播团队（年销10亿越卖越亏） | 达播高佣金吞利润，"有量无利"陷阱 |
| 花40万坑位费请大主播只卖不到3万 | 大主播坑位费泡沫，KOL投放ROI崩塌 |
| 国货底妆第一陨落（LVMH退货+供应商讨债+破产） | 过度依赖单一大主播/大客户，渠道单一化致命 |
| 超6万跨境卖家离场（利润不足5%） | 跨境内卷+关税+合规，低毛利模式不可持续 |
| 四年少了75万卖家（亚马逊清退） | 平台政策收紧持续出清中小卖家 |
| 东南亚卖家狼狈撤离（佣金齐涨利润腰斩） | 后红利时代平台抽佣上调，无差异化卖家先出局 |

**共性规律**：①流量依赖症不可持续；②毛利<10%的生意在政策收紧时最先死亡；③单一渠道/客户是致命风险；④平台补贴期=入场期，补贴退坡=出清期。

### 5.4 谨慎入局

- **直播电商(抖音)**：增速放缓+费率上调+流量红利结束，除非有强内容能力否则不建议新入
- **TEMU全托管**：欧盟税改+0佣金时代结束，低利润模式难以为继
- **国内电商平台**：存量博弈，适合有供应链优势的成熟商家，不适合新玩家
