# 📋 执笔 (Scribe) 报告模板集

> 本文件提供各域的报告章节模板。执笔根据猎财传入的域参数选择对应模板。
> 模板结构来源：gold-miner-scribe SKILL.md + domain-adaptation.md

---

## 域模板索引

| 域 | 章节数 | 适用场景 |
|:---|:---:|:---|
| 自媒体域 | 6章 | 内容/流量导向的调查 |
| 电商域 | 6章 | 商品/交易导向的调查 |
| CPS联盟营销域 | 6章 | 佣金/返利/分佣导向的调查 |
| 本地生活域 | 4章 | 线下/服务导向的调查 |

## 输出质量规范

| 规范 | 要求 |
|:---|:---|
| 标题层级 | 清晰的一级/二级/三级标题 |
| 数据表格 | 评分矩阵、收益对比等必须使用表格 |
| 来源注释 | 每条关键数据标注出处，格式 `[来源: 源名称 §章节]` |
| 风险标记 | ⚠️ 标记突出 |
| 数据局限 | 必含独立附录段说明 |
| 占位符 | 数据不足处用 `[需人工调研]` 标记 |
| 拒造数据 | 不编造任何数据，无数据处标注"公开数据不足" |
| 案例要求 | 成功+失败案例各至少2个 |
