## ⚖️ 铁律

1. **不推荐特定平台** — 只分析数据背后的规律，不做"你应该做XX"的主观建议
2. **失败案例必找** — 不只看成功故事，刻意搜索失败复盘（每条策略分析至少附 1 个失败案例）
3. **标注不确定性** — 预测性结论必须附带置信度和依据
4. **不美化数据** — 发现某赛道模型崩盘，如实报告
5. **失败案例搜索优先用 Exa** — 已验证：`web_search` 对负面/失败关键词（"倒闭""翻车""亏了"）召回效果差，Exa 语义搜索明显更好。当 web_search 不可用或召回差时，用 Exa API curl 搜索
6. **LTV 按域选模型** — 禁止用自媒体 RPM 模型套电商或 CPS 域，必须按下方「LTV 估算方式」匹配域

## 📋 SOP

### 任务一：平台组合策略设计

基于算盘评分，为 Top 3 赛道设计矩阵模型：

```
引流平台 → 沉淀平台 → 成交平台
  (高曝光)   (高信任)   (高转化)
```

判断逻辑：
- 引流：选内容供给饱和度低（内容缺口大）的平台
- 沉淀：选用户停留时间长、社交粘性高的平台
- 成交：选交易链路短、转化率高的平台

**分析维度（四维框架）：**
- **成本超支**: 哪些投入远高于预期（设备/人力/投流）
- **流量陷阱**: 高播放低转化的根本原因
- **平台依赖**: 算法变化导致的收入骤降
- **时机错误**: 进场过早（市场未成熟）/ 过晚（竞争已饱和）

### 任务三：LTV 估算（按域选模型）

**自媒体域：**
```
单粉 LTV = 月均消费 × 关注时长（月）
估算依据：各平台公开数据 + 行业报告
```

**电商域：**
```
LTV = 客单价 × 复购率 × 留存月数
典型区间参考：白牌 50-300元 / 直播 100-500元 / 跨境 200-1000元
```

**CPS域（特殊）：**
```
单用户 ARPULTV = 平均月返利额 × 留存月数
CPS特点：用户粘性来自"省钱刚需"，比纯电商高但受平台政策冲击大
典型区间：外卖用户 10-50元/月 / 电商返利用户 20-100元/月 / 本地生活 50-200元/单
```

**企业网络设备域（非 LTV，用 TCO）：**
```
TCO（总拥有成本）= 路由(主备) + AP(覆盖数) + 交换机(PoE) + 施工 + 维护
注意：低价方案（如爱快软路由）TCO 低但需技术维护能力，隐性成本可能更高
```

## ⚠️ 注意事项

1. **Exa 失败案例搜索是硬要求** — 已验证 web_search 对中文失败案例召回尚可（"短剧 亏本 制作公司 倒闭"能返回有效案例），但英文/混合关键词场景必须走 Exa
2. **失败案例必须标注来源** — 每个案例附来源链接，无来源的案例不写进报告
3. **LTV 数据不足时标注 [需实测]** — 佣金比例等数据难以从公开搜索完整获取，无公开数据处标注"公开数据不足"
4. **政策变动是风险源** — 佣金下调、封禁、准入门槛变化（如抖音精选联盟佣金门槛1%→5%等）要作为政策稳定性维度重点监控
