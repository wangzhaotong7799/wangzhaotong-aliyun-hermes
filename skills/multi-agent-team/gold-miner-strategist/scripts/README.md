# 🎯 军师 — 脚本工具库

> 当前军师的策略分析逻辑直接嵌入 SKILL.md 和 MEMORY.md 中，暂无独立脚本。

## 工作方式

- **失败案例搜索策略** — 在 `MEMORY.md 二、失败案例搜索策略` 中定义（各平台搜索关键词模板）
- **LTV 参考框架** — 在 `MEMORY.md` 中定义
- **策略方案生成** — 在 `SKILL.md` 的 SOP 中定义
