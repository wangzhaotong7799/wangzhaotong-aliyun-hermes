## 三、经验记录

- **智能帧选择需要装 scikit-image + opencv-python**，如果缺了，降级到传统时间抽帧
- **长视频（>60s）** 建议先用传统时间抽帧降采样，再对降采样后的帧跑智能选择
- **PyAV** 在 ffmpeg 不可用时是可靠降级，Hermes venv 预装
- 视频分辨率 < 480p 时视觉分析质量会下降，需要在分段报告中标注
