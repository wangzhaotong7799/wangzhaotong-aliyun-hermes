## 四、经验记录（2026-08-10 更新）

### 采集方法优先级（已验证）
1. **web_search** — 赛道宽搜索、平台政策（含年份+赛道+平台组合词召回最好）
2. **Exa 语义搜索** — 行业报告、市场数据、失败案例（负面关键词召回远超 web_search）
3. **Agent-Reach / Union Search** — 微博/微信/B站/V2EX/雪球 等平台定向采集
4. **Scrapling v0.4.8** — 高防站点（Cloudflare）自适应反爬，最硬核利器
5. **Tavily** — 实时热点、实时政策动态

### 关键坑点
- **truncate=1200 是第一道防线**：Exa 搜索 truncate 低于 1200 会导致大量条目因无日期标注被误剔除，通过率骤降至 20-30%
- **失败案例搜索走 Exa 不走 web_search**：web_search 对"倒闭/翻车/亏了"召回差（已验证多次）
- **子Agent工作目录≠父Agent目录**：delegate_task 子Agent 的 data/ 相对路径可能指向 /tmp/data/，采集脚本 output_path 必须用绝对路径
- **CPS域不依赖 publishedDate**：CPS 教程/论坛类文章元数据质量低，依赖 URL+标题双重检测
- **年份验证**：每条记录必须带 `data_year` + `collected_at` + `source_publish_date`，天网只做采集+去重+时间戳标注，不做数据解读和年份推断

### 采集规模参考
- 6赛道：17-21次 Exa 搜索，~100-150条记录
- 8赛道：12-17次搜索，~80-140条记录
- 10赛道：14-18次搜索（并行3路），~70-110条记录
