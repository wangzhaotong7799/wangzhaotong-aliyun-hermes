### 各域权重速查（完整表见 SKILL.md）
- **电商**：市场规模增速0.30 + 竞争强度0.25 + 供应链复杂度0.20 + 生命周期0.15 + 政策风险0.10
- **CPS**：佣金率0.25 + LTV 0.25 + 政策稳定性0.20 + 市场容量0.20 + 竞争强度0.10
- **本地生活**：市场增速0.30 + 竞争强度0.25 + 用户渗透率0.25 + 生命周期0.20
- **AI视频**：视频质量0.25 + 性价比0.25 + 功能完整度0.20 + 满意度0.20 + 国内可用性0.10
- **企业设备**：性价比0.30 + 稳定性0.25 + 功能完整度0.20 + 售后0.15 + 扩展性0.10

### 逆分计分约定（2026-06-29 确认，重要！）
- **逆分维度**：竞争强度、供给饱和度、供应链复杂度、政策风险、竞争格局（越低越有利）
- **原始分维度**：变现效率、生命周期、市场增速等（越高越好）
- **历史教训**：若四维全按原始分计算，美妆会因高变现×高竞争×高饱和被推至第一，与实际"最红海"严重不符。逆分处理后美妆垫底(5.05)符合实际。

### 评分逻辑
- **变现效率**: 官方报价中位数 + 场均GMV区间上限，归一化到 0-100
- **竞争强度**: 倒序计分。头部集中度越低、新入场者越少 → 分越高
- **供给饱和度**: 每日新增作品/日均互动，比值越低（供给缺口大）→ 分越高
- **生命周期**: 定性判断，萌芽最高、衰退最低

### 盈亏平衡公式
```
保底播放量 = 总制作成本 / 千次播放收益(RPM)   # 内容/流量类域
LTV = 客单价 × 复购率 × 留存月数              # 电商域
ARPULTV = 平均月返利额 × 留存月数             # CPS域
TCO = 路由+AP+交换机+施工+维护                # 硬件设备域（替代模型）
```

## 五、经验记录（2026-08-10 更新）

- **数据置信度标注是评分的一部分**：赛道有效数据 <5条 标注「置信度低」，<3条 标注「不建议采信」。2026-06-22 电商域即时零售仅4条有效数据需标注置信度低
- **年份闸门先行**：评分前必须先看猎财的 `data/quality_gate_report.md`，确认数据已剔除 <2026 记录
- **评分矩阵必须带置信度列**：输出时表头注明逆分维度（如 `竞争强度(逆)`），避免下游误读
- **异常预警**：环比 >30% 波动必须在摘要上方预警（如 TikTok Shop 政策风险加剧时评分需体现）
- **权重以猎财传参为准**：若猎财指令中的权重与速查表冲突，以猎财传参为准（域适配指南可能已更新）
