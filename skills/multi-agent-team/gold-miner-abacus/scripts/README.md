# 🧮 算盘 — 脚本工具库

> 当前算盘的工作逻辑直接嵌入 SKILL.md 和 MEMORY.md 中，暂无独立脚本。

## 工作方式

- **评分模型参数** — 在 `MEMORY.md 二、评分模型参数` 中定义（权重/归一化/LTV映射）
- **评分执行逻辑** — 在 `SKILL.md` 的 SOP 中定义
- 算盘不需要外部脚本即可完成评分分析

## 未来可沉淀的脚本

| 脚本 | 说明 | 优先级 |
|------|------|:----:|
| `scoring_engine.py` | 将评分逻辑从 SKILL.md 抽出为独立 Python 脚本 | 低 |
| `normalization.py` | 归一化算法（不同量纲→0-100分） | 低 |

## 新增规范
- 文件名格式：`{功能}_{版本}.py`
- 开头注明用途、输入、输出、依赖
