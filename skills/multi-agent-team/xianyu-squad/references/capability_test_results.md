# 闲鱼小队 · 能力测试记录

> **测试时间**: 2026-05-09 | **测试人**: Hermes Agent
> **结论**: 自动化能力有限——只能帮选品分析、写文案、算利润；上架和比价需手动

## 测试方法

对所有依赖的外部平台和工具做了逐个实机探测：

1. 用 `curl` 测试各平台HTTP可达性
2. 用 `web_extract` 测试能否提取结构化数据
3. 检查已安装的工具链（Chromium/Playwright/Selenium/Puppeteer）
4. 检查 Agent-Reach 通道是否覆盖这些平台
