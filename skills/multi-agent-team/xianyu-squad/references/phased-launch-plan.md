## 📅 Day 1 — 选品侦察（约1小时）

### 目标
从0到有，产生10-20个候选商品 + 利润排行Top10

### 执行脚本

#### Step 1.1：行业趋势搜索（🤖 我做）

```bash
# 搜索6大热门赛道，覆盖不同价格带
web_search(query="2026年闲鱼热门品类 倒卖赚钱 低成本", limit=5)
web_search(query="闲鱼 2026年 什么最好卖 新手推荐", limit=5)
web_search(query="拼多多低价爆款 闲鱼加价 2026", limit=5)
web_search(query="1688 一件代发 热门商品 2026", limit=5)
```

输出初筛：**3-5个方向**（如：家居小件 / 数码配件 / 母婴用品 / 个护家电 / 办公文具 / 宠物用品）

#### Step 1.2：浏览闲鱼热门（👤 主人做）

打开闲鱼APP，浏览以下位置：
- 首页→猜你喜欢（刷20条，截图发给我）
- 搜索框→搜索上一步选出的方向关键词
- 每个方向点开3-5个"想要"数高的商品

**发给我的内容**（每条商品按这个格式）：
```
品名：XXX
闲鱼售价：xx元
想要数：xx
闲鱼同款数量：大约xx个（搜关键词看结果数）
拼多多同款价：xx元
```

输出：**10-20个候选商品清单**

#### Step 1.3：利润验算（🤖 我做）

对每个候选品，用利润计算器跑一遍：

```bash
cd ~/.hermes/skills/multi-agent-team/xianyu-squad/scripts
python3 profit_calc.py
# 批处理模式：python3 profit_calc.py --batch products.csv
```

评分逻辑（满分100分）：
| 维度 | 分值 | 得分条件 |
|:----|:---:|:--------|
| 利润空间 | 30分 | ≥30元得30分，≥15元得15分，<10元0分 |
| 需求竞争比 | 30分 | "想要数/同款数"≥5得30分，≥3得15分 |
| 非季节性 | 20分 | 全年可卖得20分 |
| 轻小件 | 20分 | 运费≤8元得20分 |

输出：**排行榜Top10** → 主人确认前三名

### ✅ Day 1 验收标准
- [ ] 至少1个行业搜索方向被证实有利润空间
- [ ] 候选商品池≥10个
- [ ] 利润排行榜Top10已产出
- [ ] 主人确认了明早要上架的Top3

## 📅 Day 2 — 首单上架（约1.5小时）

### 目标
3个商品成功上架到闲鱼，可被搜索到

### 执行脚本

#### Step 2.1：撰写文案（🤖 我做）

对主人确认的Top3，每个商品生成3套不同风格的文案：

**套A — 真实转让风**（最推荐，闲鱼用户最喜欢）
> 标题：全新{品牌}{品名} {核心卖点} {使用场景} 未拆封
> 描述：买回来发现用不上/朋友送的/家里有同款……强调真实感

**套B — 性价比风**（适合价格敏感用户）
> 标题：{品名} 性价比超高 {对比原价} {低于市场价}
> 描述：对比实体店/网上价格，强调省了多少钱

**套C — 场景痛点风**（适合搜索流量）
> 标题：{解决什么痛点} 终于找到{品名} {使用场景}
> 描述：先讲痛点再讲解决方案

#### Step 2.2：拍照准备（👤 主人做）

- 每个商品拍3-5张实拍图
- 至少1张主图（白底或简洁背景）
- 至少1张细节/使用场景图
- **不要直接用拼多多/1688上家的图**（会被闲鱼识别降权）

#### Step 2.3：发布上架（👤 主人做）

闲鱼APP操作：
1. 点"+" → 发布闲置
2. 上传实拍图
3. 填写标题（从我给的3套中选1套）
4. 填写描述（从我给的3套中选1套）
5. 设置价格
6. 设置发货地（哈尔滨）
7. 选择"全新"或"几乎全新"
8. 打开"自动回复"（用默认模板即可）
9. 发布

## ⚠️ 常见问题

### Q1: 第一天一个品都选不出怎么办？
A: 扩大搜索范围。从家居小件（收纳盒/手机支架/数据线）这种标品开始，利润率低但需求稳定，先跑通流程再说。

### Q2: 上架了3天没出单正常吗？
A: 完全正常。闲鱼新号有3-7天冷启动期。继续每天擦亮+上新，一般第5-7天开始有流量。

### Q3: 买家问能不能便宜怎么办？
A: 不要直接降价。用"多拍一件包邮"或"送小礼物"替代降价。一旦降价，这个品就难再卖原价了。

### Q4: 拼多多代发卖家发错货怎么办？
A: 联系拼多多卖家退换（有退货包运费），同时告知闲鱼买家"发错了正在补发"。不要自己承担运费。

### Q5: 闲鱼要求上传物流单号怎么办？
A: 填拼多多给你的快递单号即可。只要单号真实可查，闲鱼认可。
