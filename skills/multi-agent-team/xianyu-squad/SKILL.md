# 🏪 闲鱼小队 v1.0 — 闲鱼倒卖全自动工作流

> **目标**: 年入5万（月均4,200元）| **启动资金**: 500元 | **启动时间**: 第1天
> **座右铭**: "信息差就是印钞机"

---

## ⚖️ 铁律

1. **不碰违规品** — 药品/医疗器械/烟草/假冒伪劣/虚拟货币，碰了封号
2. **利润门槛** — 单品利润低于10元不选，运费高于5元不选
3. **价格验证** — 每件商品必须三方比价（闲鱼→拼多多→1688），截图留证
4. **真实描述** — 商品描述不能夸大，不能用"原单""代工厂"等违规词
5. **数据驱动** — 所有选品决策基于数据，不拍脑袋
6. **安全第一** — 一机一号，不用公共WiFi操作，不点陌生链接

## 🧠 架构设计：5名Agent协同作战

> ⚠️ **重要前置步骤**：在启动工作流之前，必须执行**能力验证（Capability Verification）**。详见 `spike` 技能的"Capability Verification"章节和本小队的 `references/capability_test_results.md`。

## 📋 SOP — 4阶段工作流

### 阶段一：选品侦察（每周日 + 每日10分钟）

**触发条件**: ①每周日定期执行 ②每日快速扫描

#### 子任务A：探探·监控热门

```
委托探探 → 采集闲鱼+拼多多+1688 热门数据

数据来源：
  1. 闲鱼APP → 首页推荐、"想要"数高的商品
  2. 拼多多 → "本周热门"分类页
  3. 蝉妈妈/考古加 → 抖音热销榜单（免费版即可）
  4. 百度指数/微信指数 → 搜索上升词

采集维度：
  - 商品名称、售价、"想要"数、出单量（估算）
  - 闲鱼同类商品数量（判断竞争度）
  - 拼多多/1688同款最低价
  - 近期搜索趋势（上升/下降）

输出：Scouty_report.md（候选商品池20-30个）
```

#### 子任务B：算盘·算利润

```
委托算盘 → 对候选商品池逐品算账

算账公式：
  毛利润 = 闲鱼售价 - 拼多多进货价 - 闲鱼手续费(1%) - 预期运费(5-10元)
  净利润率 = 毛利润 / 闲鱼售价
  
评分规则（满分100）：
  - 利润≥30元：+30分
  - 利润≥15元：+15分  
  - 想要数/同行数 ≥ 5（高需求低竞争）：+30分
  - 非季节性商品（全年可卖）：+20分
  - 轻小件（运费≤8元）：+20分

输出：Abacus_scores.md（按分数排序，Top10进入备选池）
```

### 阶段二：策略决策（每周日）

#### 子任务C：军师·定策略

```
委托军师 → 从算盘输出的Top10中选出本周上架的3-5个品

决策维度：
  1. 利润空间是否稳定（检查上家价格近7天波动）
  2. 是否存在节日/季节窗口
  3. 竞争是否正在加剧（近3天上架数趋势）
  4. 是否适合"多号"操作（一个品挂多个号）

定价策略：
  - 基于算盘计算的最低利润，加价20-30%
  - 参考同行最低价，略低或持平
  - 设置"0.01元"小附件拉高客单价

输出：Strategist_decisions.md（选品+定价+策略说明）
```

### 阶段三：上架执行（选品后立即）

#### 子任务D：执笔·写文案

```
委托执笔 → 为每个选定的品生成3套不同风格的文案

文案模板：
  【标题】关键词 + 卖点 + 状态词
    例：「全新XX品牌保温杯 学生大容量 办公室用 未拆封」
  
  【描述】5要素：
    ① 使用场景（真实）
    ② 产品亮点（2-3个）
    ③ 为什么出（真实感）
    ④ 实物拍摄（去上家图，自己拍）
    ⑤ 售后承诺（7天退换）
    
  【图片】
    ① 主图：实拍图（避免直接用上家图）
    ② 细节图：使用场景、包装
    ③ 对比图：与同类产品对比

输出：3套文案成品（Scribe_listings.md）
```

#### 子任务E：飞飞·上架

```
委托飞飞 → 执行上架操作

操作步骤：
  1. 闲鱼APP → 发布 → 拍照上传
  2. 填写标题/描述（使用执笔产出）
  3. 设置价格（使用军师策略）
  4. 打开"自动回复" 
  5. 每天擦亮1次（闲鱼币免费擦亮）
  6. 每天上新2-3个品

输出：上架确认清单
```

### 阶段四：运营跟单（每日）

#### 飞飞·日常运营

```
委托飞飞 → 每日运营操作清单

必做：
  □ 检查消息 → 2小时内回复
  □ 自动回复 → 设置快捷回复（发货时间/价格/退货政策）
  □ 已卖出 → 拼多多下单 → 填写真实单号
  □ 收货后 → 确认收款 → 请买家好评

选做：
  □ 擦亮商品（闲鱼币免费）
  □ 上新1-2个品
  □ 下架7天未出单的商品
  
每月最后一天：
  生成运营月报（收入/支出/利润/改进建议）
```

## 🚀 启动检查清单

### 第1天 — 基础设施
```
□ 下载闲鱼APP → 淘宝账号登录 → 实名认证 → 授权芝麻信用
□ 个人信息填写度达到85%以上
□ 拍3-5件家里闲置挂上去（练手熟悉流程）
□ 注册拼多多账号（买家版即可）
□ 注册1688账号（阿里系账号直接登录）
```

### 第2-3天 — 选品试跑
```
□ 探探：采集20个热门商品
□ 算盘：算出利润Top10
□ 军师：选定第一个品类（建议日用品/小家电，不易出问题）
□ 执笔：写3套文案
□ 飞飞：上架3个品
```

### 第4-7天 — 验证跑通
```
□ 观察出单情况
□ 记录问题和经验
□ 调整选品策略
□ 出第一单！ → 从拼多多代发
```

### 第2-4周 — 放大
```
□ 增加到10-15个活跃商品
□ 日稳定出单3-5单
□ 日利润60-100元
□ 注册第2个闲鱼号（不同手机号）
□ 测试多号同时运营
```

## ⚠️ 风险与避坑

| 风险 | 概率 | 应对 |
|------|:----:|------|
| 买家退货 | 中 | 拼多多有退货包运费，直接让买家退到上家地址 |
| 上家缺货 | 低 | 选品时选2-3个备选上家 |
| 闲鱼封号 | 低 | 一机一号，不用第三方软件，不频繁发重复内容 |
| 利润太低 | 中 | 定期复盘，下架利润率<15%的商品 |
| 运费超预期 | 中 | 选品时优先轻小件，控制在8元以内 |
| 同行杀价 | 高 | 差异化：换主图、改标题关键词、加赠品 |
