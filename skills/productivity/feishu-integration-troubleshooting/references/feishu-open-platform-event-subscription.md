# 飞书开放平台事件订阅配置

## 问题：群成员 @Bot 但 Bot 完全收不到消息

**症状**:
- 你自己（应用创建者）@Bot 能正常对话
- 群里的其他人 @Bot，Bot 无任何响应
- 网关日志中查不到该用户发送消息的任何记录（无 inbound、无 reject、无 warning）

**根因**: 飞书开放平台 App 的「消息接收模式」默认设为「仅应用创建者」，其他人 @Bot 的消息被飞书直接过滤，不会推送到你的服务器。

## 修复步骤

在飞书开放平台控制台修改配置：

1. 打开 https://open.feishu.cn/app/
2. 找到你的 App（查看 `.env` 中的 `FEISHU_APP_ID`）
3. 左侧菜单 → **事件订阅**
4. 找到 `im.message.receive_v1` 事件 → 点击**配置**按钮
5. 找到 **消息接收模式**：
   - ❌ `仅应用创建者`（默认）— 只有 App 创建者 @Bot 能收到
   - ✅ `所有人` — 群聊中任何人 @Bot 都能收到
6. 改为**「所有人」**，保存
7. 重启 Hermes 网关：`hermes gateway restart`

## 补充：确认其他相关权限

在**权限管理**页面，确认以下权限已添加（如果还未添加）：

| 权限 | 用途 | 是否必须 |
|------|------|----------|
| `im:message` | 收发消息 | ✅ 必须 |
| `im:chat:read` | 读取群信息、成员列表 | ✅ 建议 |
| `im:resource` | 下载图片/文件等消息资源 | 按需 |

权限申请后需要发布版本（**版本管理与发布**）才能生效。

## 检查自己的 App 配置

```bash
# 查看当前 App ID
grep FEISHU_APP_ID ~/.hermes/.env
```

在飞书控制台顶部能看到 App ID，确认是同一个。
