## AKShare 可用符号说明

`ak.stock_index_pe_lg()` 支持的 symbol 参数（来自乐咕乐股）：

- **上证50**、**沪深300**、**上证380**、**创业板50**、**中证500**
- **上证180**、**深证红利**、**深证100**、**中证1000**
- **上证红利**、**中证100**、**中证800**

**缺失：** ❌ 创业板指(399006)、❌ 科创50(000688)、❌ 恒生指数/科技、❌ 标普500/纳指

这些缺失指数需要从蛋卷基金首页的大表或雪球/ETF.run获取当前数据。

## 创业板指 vs 创业板50 差异

创业板指(399006) = 创业板市值前100只
创业板50(399673) = 创业板市值前50只
两者走势高度相关，但PE值有差异。用创业板50做历史分析时需注明"参考误差"。

| 平台 | PE值 | 百分位 |
|:--|:--:|:--:|
| 蛋卷基金 | 14.64 | 91.76%（近10年） |
| 乐咕乐股 | 13.91（TTM市值加权） | — |
| 理杏仁 | 14.64（市值加权） | 97.52%（3年） |
| 亿牛网 | 14.13 | 63.3%（近10年） |
| value500 | 14.69 | 90.83%（近10年） |

差异原因：PE计算口径（静态 vs TTM）、百分位时间区间、是否剔除负值、数据源（Wind vs 自行计算）。

## 推荐策略

1. **当前数据**：以蛋卷基金为准（统一口径、覆盖面广）
2. **历史数据**：用AKShare获取乐咕乐股日线数据做自定义分析
3. **交叉验证**：对比value500和蛋卷数据确认一致性
4. **标注**：输出务必备注来源和口径
