# 排版样式示例

本文件展示 `beautiful-report-formatting` 技能的核心排版元素，供快速参考和复用。

---

## 1. 核心结论框（box-drawing）

用于执行摘要/核心发现，让读者30秒抓住要点：

```
┌──────────────────────────────────────────────────────────┐
│  📌 核心结论                                               │
│                                                           │
│  1. 抖音电商2025年GMV 3.5万亿(+70%)，已成国内第二大电商     │
│  2. 小红书买手电商爆发，素人2万粉月销200万+                 │
│  3. 短剧80-90%项目无法回本，但出海增速126%                  │
└──────────────────────────────────────────────────────────┘
```

**规范**：
- 宽度不超过80字符（适配飞书/终端显示）
- 左上角用 `📌` 标注标题
- 框内缩进2空格
- 如有多组结论，编号1/2/3

## 3. 竞争格局矩阵

```
        增速↑
          │
          │     🚀 赛道A              🚀 赛道B
   高速   │     +70%                  +126%
          │
          │     ➡️ 赛道C              ➡️ 赛道D
   稳健   │     +30%                  翻倍
          │
          │     ⏳ 赛道E              ⏳ 赛道F
   早期   │     早期孵化               全球占比2%
          │
          └───────────────────────────────→ 体量→
                十亿级       百亿级     千亿级     万亿级
```

**标注符号**：🚀高速增长 ➡️稳健发展 ⏳早期孵化 ⚠️风险警示

## 4. 评分矩阵

| 评分维度 | 权重 | 抖音电商 | 小红书买手 | 短剧制作 |
|:---------|:---:|:--------:|:---------:|:--------:|
| 市场规模 | 20% | 10/10    | 6/10      | 7/10     |
| 增速     | 20% | 7/10     | 9/10      | 8/10     |
| 盈利空间 | 15% | 7/10     | 8/10      | 5/10     |
| 竞争烈度 | -10% | 7/10⚠️  | 5/10✅    | 8/10⚠️   |
| 门槛     | 10% | 7/10     | 6/10      | 6/10     |
| 政策风险 | 10% | 6/10     | 7/10      | 6/10     |
| 可持续性 | 15% | 8/10     | 9/10      | 6/10     |
| AI赋能   | 10% | 9/10     | 8/10      | 8/10     |
| **加权总分** | **100%** | **7.5** | **7.4** | **6.2** |

**规范**：
- 权重列居中，分数列居中
- 权重合计100%，竞争烈度是负权重（-10%）
- 最后一行`加权总分`粗体高亮，最佳分数也粗体
- 风险维度和优势维度分别用⚠️和✅标注
