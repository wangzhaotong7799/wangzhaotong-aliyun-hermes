# 电商比价与购买建议研究

## 触发条件
用户问"想买X，有什么建议""网上哪里价格便宜""哪个平台买划算"等购物决策问题。

## 核心原则
**价格必须实际验证，禁止从搜索摘要/社区文案推断售价。** 用户对价格准确性要求高，报错一次"价格不准"就失去信任。宁缺毋滥：拿不到实据就明说，不编不猜。

## 流程

### 1. 确认产品身份
先确定品牌+型号+货号，避免张冠李戴：
- 品牌系列名常对应多个产品线（例：伯希和"轻云-3.0"是徒步鞋 HT-轻云3.0 / 货号116381041，不是冲锋衣）
- 用 web_search 确认产品是什么、哪个平台在售、SKU/货号，再谈价格

### 2. 实际验证价格（按可靠性排序）
已验证可靠的路径：
- **淘宝逛一逛 guangtao.taobao.com**：web_extract 可抓到实时聚合价格，含多家店铺标价+成交数（实抓例：伯希和轻云3.0 全店统一 ¥659-669）。入口：搜索结果里带 guangtao.taobao.com/product-<hash>.html 的链接直接抓
- **什么值得买 wiki.smzdm.com 商品页**：历史价格趋势/常卖价/历史最低，可作大促预期参考（⚠️ 必须确认是同一款——老款历史价不能用于新款）
- **IT之家 ithome.com 新品/降价报道**：新品上市官方定价+国补/活动到手价+直达链接，新品比价的第一手锚点（实抓例：京东京造M10 官方定价369元/国补后305元；M10 Pro 469元/国补422元/晒单返后392元）。搜索"品牌+型号+ithome"即可命中
- **什么值得买 品牌聚合页 smzdm.com/ju/<id>**（如 ju/snkw189 凯迪仕）：按品牌聚合京东/拼多多/天猫/直播爆料，每条带渠道+实付价+日期（例：凯迪仕V9 拼多多328.91元@2026-08-26 vs 京东自营587元），比 wiki 商品页更新鲜、跨渠道对比更直观

已知限制与备选路径：
- **京东**：item.jd.com / item.m.jd.com / p.3.cn 价格接口 / api.m.jd.com 反爬严格（browser code 244、curl 连接失败）。不要反复重试浪费轮次。备选：① web_extract 抓 jd.com/jiage 行情列表页（能拿到自营商品链接+评价数，价格数字是 JS 渲染抓不到）② 把京东自营商品链接直接给用户，请用户自己看实价
- **淘宝商品详情页 pcdetail.taobao.com**：价格 JS 渲染，web_extract 抓不到，别浪费时间
- **识货社区笔记 m.shihuo.cn**：是种草文案，文内价格区间（如"500档以内"）是修辞不是售价，不可作为价格依据
- **搜索摘要里的价格**：片段、可能过时、可能是其他 SKU 或老款的价格，只能当线索，不能当结论直接报

### 3. 渠道对比与建议
- 标价 vs 到手价：旗舰店促销价、券后价、直播间价通常低于标价，报价格要区分
- 大促节点（618/818/双11）通常可叠券，历史爆料价（smzdm 爆料页）可参考，但需确认同款同 SKU
- 风险提示：核心卖点型单品（如 Vibram 大底）拼多多散店假货风险高，建议官方旗舰店/京东自营，并在建议里点明
- **同款跨渠道价差可能极大**（实测凯迪仕V9：拼多多¥319-329 vs 京东自营¥587，差40%+）：报价必须标注渠道；安全敏感品类（门锁/安防/电子锁）拼多多只认百亿补贴/官方旗舰店

### 4. 拿不到实据时的兜底
多个渠道都验证失败时：诚实说明哪些平台价格拿不到、哪些拿到了，给出已验证价格，**主动问用户看到的实际价位是多少**，再针对性给建议。绝不硬编一个数字凑答案。

## 用户偏好（主人）
- 结论先行，渠道用表格对比
- 价格宁缺毋滥，不编不猜；认错要直接，不找借口
- 沟通直接精简，不要冗长解释
