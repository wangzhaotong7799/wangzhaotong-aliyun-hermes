## 🧑‍💼 各角色职责

### 📡 总管（Orchestrator）
- 接收用户指令（\`@总管 用故事X做一期\`）
- 分派任务到各agent
- 调度资源（BGM库、可灵AI调用、API配额）
- 质量门：最终视频审核后再推送
- 每周排期管理

### 🕵️ 搜鬼（Story Hunter）
- 对标金脉·天网，专注鬼故事源
- 已验证源：meiriyuedu.cn（直接可爬）、知乎/贴吧恐怖话题
- 未验证源：番茄小说（有反爬，此前失败）、公众号恐怖故事
- 输出：清洗后故事文件 `story_XX_标题.txt` 存入 `stories/`
- 每个故事约200-1200字，符合短视频时长

### ✍️ 编剧（Scribe）
- 故事清洗（`clean_text` → 智能缩写保开头保高潮）
- 分段（`split_into_segments` → 每段≤20字手机优化）
- 标题命名（字数≤4字，符合封面布局）
- 输出分镜表给画师：
  ```
  场景1: "李大爷是个坟地管理员..."  →  深夜坟场，孤零零的木屋
  场景2: "当晚李大爷做了个梦..."    →  昏暗小屋内，李大爷满头大汗地睡觉
  ...
  ```

### 🎨 画师（Artist）
- 接收编剧的分镜表
- 调用可灵AI/通义万相为每个场景生成对应图片
- 分辨率 1080×1920（竖版）
- 输出命名 `scene_001.jpg` ~ `scene_NNN.jpg` 顺序编号
- 风格统一：暗色调、恐怖氛围、与现有「夜半低语」封面配色一致

### 🎙️ 音频师（Audio Engineer）
- edge-tts TTS 配音（YunyangNeural 成熟男声）
- 语音后处理（volume=5.0 + alimiter + equalizer 80Hz/3kHz + aecho）
- BGM多曲拼接（combine_bgm_files → acrossfade 3~4首）
- 输出：`voice_processed.wav` + `bgm_combined.wav`

### 🎬 导演（Director）
- FFmpeg 视频合成核心（assemble_video_v7）
- 动态背景：按画师提供的场景图序列切换（不是单图循环）
- 字幕渲染：庞门正道标题体故事名 #B10000 96px + Noto Black字幕54px
- 输出：成品 `yeban_v7_XXX.mp4`

### 📡 推送师（Publisher）
- 为各平台准备不同格式（抖音竖版、小红书封面、B站横版等）
- 生成标题文案 + 标签 + 简介
- 管理发布排期（一周几更、每天固定时间发）
- 记录已发布清单（防重发）
- 能调用平台接口的自动发，不能的生成发布包供手动投
