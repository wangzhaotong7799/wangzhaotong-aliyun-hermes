# 恐怖BGM合成指南 v3

## 原理
用 Python numpy 合成多频段波形叠加，模拟恐怖配乐。
不需要任何外部音频素材，纯代码生成，零成本。

## 架构（6层叠加，full风格）

```
低音嗡鸣(35Hz次谐波) ──┐
风噪(低通白噪声) ──────┤
钢琴旋律(A小调) ───────┼──→ 混合 → 归一化 → WAV输出
弦乐垫(和弦进行) ──────┤
不和谐音簇(音爆) ──────┤
心跳(65BPM可选) ──────┘
```

## v3 新增层详解

### 3. 钢琴旋律 (Horror Piano)
- 音阶: A小调（半音: 0, 3, 5, 6, 7, 10, 13, 15, 17, 18, 22）
- 三全音 (6 semitones) 权重更高 — 最不和谐音程
- 音色: 正弦波 + 二次泛音(30%) + 三次泛音(10%)
- 包络: 快速起音 + 指数衰减 (τ=300ms)
- 密度: `density=0.3`（约每3秒一个音符）
- 跨八度: 随机选 ±12/24 半音

### 4. 弦乐垫 (String Pad)
- 和弦池: Am (0,3,7) / Dm (5,8,12) / Em (7,10,14) / F (8,12,15) / Cdim (3,6,10)
- 音色: 40%正弦 + 40%锯齿 (saw wave 弦乐质感)
- 颤音: 0.15Hz 缓慢振幅调制
- 和弦切换: 每4-8秒随机更换
- 音量: 0.04（背景层）

### 5. 不和谐音簇 (Atonal Swell)
- 每段2-4次随机出现
- 频率: 200-800Hz 随机3-6个频率叠加
- 包络: sin² 渐强→渐弱
- 音量: 0.06

## BGM风格参数

| 风格 | 包含层 | 适用场景 |
|:---|:---|:---|
| `full` (默认) | 全部6层 | 恐怖故事完整配乐 |
| `melodic` | 钢琴+弦乐+不和谐音 | 偏音乐性，适合悬疑 |
| `ambient` | 低音嗡鸣+风噪 | 纯氛围，适合背景 |

## 音量混合（FFmpeg）

```
# BGM 18% 混入配音
[1:a]volume=0.18[bgm];[0:a][bgm]amix=inputs=2:duration=first:dropout_transition=2
```

## 输出规格
- WAV, 22050Hz, 16-bit, mono
- 30秒 ~1.3MB
- 生成耗时: ~10-15秒 (30秒BGM)

## 避坑
- 钢琴音符过多会变得"悦耳"而非恐怖 → density控制在0.3以下
- 弦乐垫用小调和弦+减三和弦（Cdim）制造紧张感
- 22050Hz采样率足够BGM用，44100Hz会翻倍生成时间但听感提升不大
- numpy的sin/cos计算是瓶颈，30秒full风格约需8-12秒
